# Claude Code Agent

Claude Code is Anthropic's official CLI for Claude. It's one of the primary agents supported by orch.

## Prerequisites

Install Claude Code following Anthropic's documentation:

```bash
# Via npm
npm install -g @anthropic-ai/claude-code

# Verify installation
claude --version
```

## Configuration

### Basic setup

```yaml
# .orch/config.yaml
agent: claude
```

### With custom prompt

```yaml
agent: claude

claude:
  prompt_template: |
    ultrathink Please read 'ORCH_PROMPT.md' in the current directory.
    Follow the instructions carefully.
    
    {{issue}}
```

## Running with Claude

```bash
# Use default agent (if configured as claude)
orch run my-issue

# Explicitly specify claude
orch run --agent claude my-issue
```

## How orch uses Claude

When starting a run, orch:

1. Creates a tmux session
2. Changes to the worktree directory
3. Launches claude with the prompt:
   ```bash
   claude "Your prompt here..."
   ```
4. By default, uses `--dangerously-skip-permissions` for non-interactive use

## Agent Detection

The orch daemon detects Claude's state by monitoring terminal output:

### Running indicators
- Token counter visible
- Output actively scrolling
- Claude UI elements present

### Blocked indicators
- "↵ send" prompt visible
- "? for shortcuts" visible
- "accept edits" prompt
- "shift+tab to cycle"

### Exit indicators
- Shell prompt visible (`$`, `%`, `❯`)
- No Claude UI elements

## Prompt Best Practices

### Use ultrathink

Start prompts with `ultrathink` for thorough analysis:

```yaml
claude:
  prompt_template: |
    ultrathink Please read 'ORCH_PROMPT.md' and follow the instructions.
    {{issue}}
```

### Include ORCH_PROMPT.md reference

The `ORCH_PROMPT.md` file is auto-generated by orch with issue context:

```yaml
claude:
  prompt_template: |
    Please read 'ORCH_PROMPT.md' in the current directory.
    It contains the issue specification and instructions.
```

### Direct issue embedding

Or embed the issue directly:

```yaml
claude:
  prompt_template: |
    ## Task
    {{issue_title}}
    
    ## Details
    {{issue}}
    
    ## Instructions
    - Implement the requirements
    - Write tests
    - Create a PR when done
```

## Profiles

Use Claude profiles for different configurations:

```bash
orch run --agent claude --profile work my-issue
```

Configure default profile:

```yaml
claude:
  profile: work
```

## Permissions

By default, orch runs Claude with `--dangerously-skip-permissions` for automation:

```bash
claude --dangerously-skip-permissions "prompt..."
```

This allows Claude to:
- Read/write files without asking
- Execute commands without confirmation
- Make git commits and pushes

**Security note:** Only use this in trusted environments with proper git branch protection.

## Interacting with Claude

### Attach to session

```bash
orch attach my-issue
```

This opens the tmux session where Claude is running. You can:
- See Claude's work in real-time
- Type messages to Claude
- Paste images
- Provide input when Claude asks questions

### Detach

Press `Ctrl+B` then `D` to detach without stopping Claude.

### Send a message

Send input without attaching:

```bash
orch send my-issue "Please also add documentation"
```

## Troubleshooting

### Claude not responding

1. Check if session exists:
   ```bash
   orch ps
   ```

2. Check daemon logs:
   ```bash
   tail -f .orch/daemon.log
   ```

3. Attach and check Claude's state:
   ```bash
   orch attach my-issue
   ```

### Permission errors

If Claude keeps asking for permissions:

```yaml
claude:
  skip_permissions: true  # Ensure this is enabled
```

### Model selection

Claude Code automatically uses the appropriate model. Model selection is handled by Claude Code's own configuration, not orch.

### API errors

If you see API rate limits or authentication errors:

1. Check your Anthropic API key
2. Verify billing status
3. Check Claude Code logs

## Advanced Configuration

### Custom startup command

For special requirements:

```yaml
claude:
  command: claude --profile work --dangerously-skip-permissions
```

### Environment variables

Pass environment to Claude:

```yaml
claude:
  env:
    ANTHROPIC_API_KEY: ${ANTHROPIC_API_KEY}
    CLAUDE_CONFIG_DIR: ~/.claude
```

### Working with the Claude UI

Claude has various UI modes and features. In tmux sessions:

- Scrollback: `Ctrl+B [` then use arrow keys
- Exit scroll mode: `q`
- Copy text: Select with mouse, then `Ctrl+B ]` to paste

## Status Mapping

| Claude State | orch Status |
|--------------|-------------|
| Initializing | `booting` |
| Actively working | `running` |
| Waiting for input | `blocked` |
| Completed task | `done` |
| Error message | `failed` |
| Exited to shell | `unknown` |
